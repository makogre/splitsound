# Bilder für die Dokumentation

Der README verweist auf diese Dateien. Solange sie fehlen, zeigt GitHub an der
Stelle einen leeren Rahmen.

| Datei | Was drauf sein sollte |
|---|---|
| `mixer.png` | Der geöffnete Mixer in der Menüleiste, mit zwei bis drei Apps in der Liste |
| `zeile.png` | Nahaufnahme einer einzelnen Kanalzeile: Icon, Name, Prozentwert, Stumm-Schalter, Regler |

Aufnehmen mit <kbd>⌘</kbd><kbd>⇧</kbd><kbd>4</kbd>, dann <kbd>Leertaste</kbd> und
auf das geöffnete Menü klicken — so wird das Fenster samt Schatten und
transparentem Hintergrund freigestellt.

Breite im README ist auf 360 px gesetzt; ein Retina-Screenshot (also etwa
720 px breit) sieht dort am schärfsten aus.
